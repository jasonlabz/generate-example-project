# GoMock Script Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide a safe, configurable project-wide GoMock generator with path filtering and Go `internal` visibility support.

**Architecture:** `script/go-mockgen.sh` owns CLI parsing, safe generated-file cleanup, destination mapping, and PATH-based `mockgen` invocation. `script/internal/mockscan` remains a standard-library Go scanner, extended only to select source roots deterministically. Integration tests run a copied miniature project with a compiled fake `mockgen`, so they validate the shell contract without modifying the repository's real mocks.

**Tech Stack:** Bash (Git Bash on Windows), Go standard library (`go/ast`, `filepath`, `os/exec`), GoMock CLI installed on PATH.

## Global Constraints

- Keep `server/mocks` as the default `-o` output directory.
- Accept `-p path1,path2,...`, `-o output-root`, `-s strip-prefix`, and `-h`.
- Resolve every source and output path beneath the project root; reject paths outside it.
- Invoke `mockgen` from PATH; report the `go install go.uber.org/mock/mockgen@latest` command when unavailable.
- Never recursively delete the output root. Delete only `mock_*.go` files containing `Code generated by MockGen` below it.
- Skip `*_test.go`, `*.gen.go`, `vendor`, `.git`, `.mocks`, and the selected output tree.
- Generate only exported top-level interfaces, using package name `mocks`.
- For an unsafe `internal` destination, redirect to the relevant internal parent tree's `.mocks/` directory and print that destination.
- Do not commit any change in this delivery; the user explicitly requested that state.

### Task 3: Implement the safe, configurable shell generator

**Files:**

- Modify: `script/go-mockgen.sh`
- Test: `script/go_mockgen_test.go`

**Interfaces:**

- Consumes: `-p path1,path2,...`, optional `-o output-root`, optional `-s strip-prefix`, and `mockgen` on PATH.
- Produces: generated mock files at `<output-root>/<source-relative-directory>/mock_<source-file>.go`, subject to strip and internal routing rules.

- [ ] **Step 1: Replace the single-required-output parser with documented options**

Use defaults and `getopts` matching the user-facing contract:

```bash
paths='.'
mock_root='server/mocks'
strip=''

while getopts 'hp:o:s:' opt; do
  case "$opt" in
    h) usage; exit 0 ;;
    p) paths=$OPTARG ;;
    o) mock_root=$OPTARG ;;
    s) strip=$OPTARG ;;
    *) usage; exit 2 ;;
  esac
done
```

Reject trailing positional arguments. Normalize Windows absolute paths with `cygpath --unix`; after canonicalization, reject a source or output path that is outside `$project_root`.

- [ ] **Step 2: Require and invoke PATH `mockgen`**

Before scanning, enforce the selected dependency source:

```bash
command -v mockgen >/dev/null 2>&1 || {
  echo 'error: mockgen not found in PATH' >&2
  echo 'install: go install go.uber.org/mock/mockgen@latest' >&2
  exit 1
}
```

For each candidate invoke exactly:

```bash
mockgen -source="$source_path" -destination="$target" -package=mocks
```

- [ ] **Step 3: Implement safe cleanup and source-root scanning**

After validating `mock_root`, remove only generated mock files below it. Check the marker before deletion and retain all other files:

```bash
while IFS= read -r -d '' candidate; do
  if grep -q '^// Code generated by MockGen\. DO NOT EDIT\.' "$candidate"; then
    rm -- "$candidate"
  fi
done < <(find "$mock_root" -type f -name 'mock_*.go' -print0)
```

Split `paths` on commas, skip absent directories with a message, require at least one valid directory, and pass each valid absolute directory as `-path` to `go run ./script/internal/mockscan`. Pass the normalized output root as `-exclude`.

- [ ] **Step 4: Implement deterministic destination mapping**

For normal files, remove `"$strip/"` only when it is a complete leading path segment, then generate into the mirrored subdirectory below `$mock_root`. For paths containing an `internal` segment, first determine whether the mapped destination lies under that internal segment's parent. If it does not, use this legal destination instead:

```text
<internal-parent>/.mocks/internal/<suffix after internal>/mock_<filename>.go
```

Print `redirect internal mock: <source> -> <destination>` before calling `mockgen`. When `-o internal/mocks -s internal` is used for a top-level `internal` source, the normal mirrored destination is already legal and must be retained.
