## 关键决策、单一职责与疑虑

- Service 层拥有 `HealthCheckService`，Controller 以构造函数注入它；这是用户确认的显式层契约，且 GoMock 可以直接替换。
- `HealthCheckResult` 不含 HTTP tag；`convertor.go` 负责映射到 `response.Envelope`，避免业务结果和 Huma DTO 耦合。
- Router 继续是唯一 composition root；没有引入全局 Service Locator、DI 容器或额外 UseCase 层。
- 无已知阻塞或残留风险；Windows Git 的 LF/CRLF 提示为本仓库现有 attributes 行为，`gofmt`、生成与 `git diff --check` 均通过。
